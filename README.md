## 4. Conversas com as Fontes

**Pergunta 1:** O que é engenharia de prompts e por que ela possibilita resultados melhores?
**Resposta do Notebook:** Engenharia de prompts é a prática de projetar instruções claras e específicas para guiar modelos de IA generativa. Ela possibilita resultados melhores porque reduz ambiguidade e dá contexto, formato e exemplo ao modelo. [Fonte 3, Fonte 4]

**Pergunta 2:** Quais são os principais componentes de um bom prompt?
**Resposta:** Persona, Contexto, Tarefa, Formato e Exemplo. Ex: "Aja como um professor (persona), explicando para iniciantes (contexto), explique o que é alucinação (tarefa), em 3 tópicos (formato)". [Fonte 3, Fonte 5]

**Pergunta 3:** Como um prompt tendencioso pode induzir erro?
**Resposta:** Quando o prompt já sugere a resposta desejada, como "Por que a linguagem X é a pior?". Isso limita a análise do modelo e enviesa a resposta. [Fonte 4]

**Pergunta 4:** O que é alucinação e como evitar?
**Resposta:** Alucinação são informações erradas ou inventadas pelo modelo com aparência de verdade. Evita-se pedindo para citar fontes, dando contexto e instruindo para dizer "não sei" quando não houver dados. [Fonte 5, Fonte 3]
